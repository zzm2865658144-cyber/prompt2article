# 提示词范例

提示词写得越具体，大纲质量越高。下面按风格给一些可直接用的例子。

## 开头怎么写更有效

差的写法：

```
写一篇关于 AI 的文章
```

好的写法包含三件事——**具体主题 + 读者 + 你想要的落点**：

```
面向产品经理，讲清楚大模型推理成本这两年为什么降得这么快，
重点解释 MoE 和量化各自的贡献，不要写成技术综述。
```

## 科普 `--style science`

```
解释为什么天空是蓝色的，面向初中生，不要用麦克斯韦方程。
```

```
讲清楚"世界线收束"这个科幻设定在物理学里对应的真实概念是什么、
哪些是虚构的，面向完全没学过相对论的读者。
```

## 评论 `--style opinion`

```
短视频是否真的让人变笨？给出你的判断，并且正面回应"没有证据表明"
这一方最有力的论据。
```

```
"AI 会取代程序员"这个说法里，哪一部分是对的、哪一部分是错的？
要求观点明确，不要两边讨好。
```

## 教程 `--style tutorial`

```
用 Python 从零写一个命令行番茄钟：给出完整可运行代码、
说明为什么用 argparse 而不是自己解析 sys.argv、
列出 Windows 上会遇到的坑。
```

## 叙事散文 `--style essay`

```
写一个关于"深夜便利店"的短篇散文，通过值班店员的视角，
不要直接抒情。
```

## 学术 `--style academic`

```
综述近五年图神经网络在分子性质预测上的主要方法，
说明各类方法的适用边界和评测上的已知问题。
```

## 公众号 `--style wechat`

```
写给刚工作的年轻人：为什么第一份工作不该只看薪水。
开头要抓人，结尾要有一句能被转发的话。
```

## 技术博客 `--style tech`

```
我们为什么把消息队列从 Kafka 换成了 NATS：
讲清楚原来的痛点、迁移中踩的坑、以及这次替换付出的代价。
```

## 演讲稿 `--style speech`

```
毕业典礼上的三分钟致辞，主题是"允许自己走弯路"，
面向即将进入社会的学生，要适合朗读。
```

## 配合其他参数

```powershell
# 指定读者 + 字数 + 风格
python -m prompt2article "解释什么是零知识证明" `
    --audience "有编程基础但没学过密码学" --style science --words 1800

# 从文件读长提示词
python -m prompt2article --file topic.txt --style tech --polish

# 英文输出
python -m prompt2article "why static typing helps large codebases" --language en
```
